How the α/β calibration works here

The raw readouts are plain atan2 over the magnet reply. The calibrated ones run the same Desmos model as the SFI page — the shared angle_calib.js module. The formula above rewrites the α and β angles so each of them sees two components: an in-plane (tangential) one X/Y and a perpendicular Z one, with the cross-axis mixing scaled out by k and the orthogonality terms.

What feeds the formula (signal mapping by mode):

  • 1px mode (units: mT) — pixel 0’s absolute field: x1 = Bx, y1 = By, z1 = Bz. α lives in the X–Z plane, β in the Y–Z plane.
  • 2px mode (units: mT/mm) — the differential channels between adjacent pixels: x1 = X02, y1 = Y13, and z1 = Z02 for α / Z13 for β. Here the “companion” inside a1’s square root is the perpendicular gradient, so tilts along one axis are measured against the opposite pair’s gradient channel.

The six constants:

  • k1, k2 — K-factors. Scale the cross-axis component feeding each angle: 1.0 keeps it as measured, >1 amplifies it, <1 attenuates it. Use these when one axis reads stronger/weaker than the geometry really is (gain trim).
  • o11, o12 — α orthogonality terms; o21, o22 — β orthogonality terms. Each subtracts the Z feedthrough from an in-plane axis (lower term, o12/o22, acting on x1/y1) or the in-plane feedthrough from the Z leg (upper term, o11/o21, acting inside the square root). Non-zero values cancel mounting or sensitivity crosstalk.

Defaults are not raw. With k = 1 and every o = 0 the cross-axis term is still fully in, so the calibrated angle is the 3D direction angle (e.g. α = atan2(√(z1² + y1²), x1)), not the two-signal raw angle; the columns match only when that cross term is zero. Setting k = 0 removes it, and the calibrated angle then uses |z1| where raw keeps the sign of z1. Values normalize live; non-finite inputs never break the loop.
