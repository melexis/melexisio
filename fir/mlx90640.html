Stops at 16 Hz on purpose: a frame is 1668 bytes of hex over USB CDC, and above this the sensor starts overwriting what is still being read. Writes bits 9:7 of the control register.
The part is calibrated in chess mode, and Melexis recommends it: interleaved has visibly worse fixed-pattern noise, which reads as a chequerboard. Writes bit 12 of the control register straight away.
7-bit, 0x08 to 0x77. Detect passes the address it found; the last one used here is remembered. Applies on the next connect.

Measurement

Applied in the browser, so changes take effect on the next frame. Leave Reflected at roughly Ta − 8 °C unless a specific background temperature is known.

      Each frame carries only half the pixels — the sensor alternates two subpages — so the image
      is built from the last two frames rather than one. Calibration constants are read from the
      sensor's EEPROM once per session and the per-pixel maths runs here, ported from the Melexis
