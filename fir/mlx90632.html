      Unlike the array sensors, this part reports a single zone, so the reading is a number over
      time rather than an image. Calibration constants are read from EEPROM once per session and the
      object temperature is solved iteratively in the browser, ported from the Melexis MLX90632
      driver library (Apache-2.0). Medical measurement type only; the extended range mode uses a
      different EEPROM block and raw-read path.
