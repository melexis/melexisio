      Every frame carries all 192 pixels — the two subpages differ in which offset set applies, not
      in which pixels are present — so no accumulation is needed. The EEPROM is Hamming-encoded and

      wrong. Maths ported from the Melexis MLX90641 driver library (Apache-2.0).
