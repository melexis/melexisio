Every address is tried three ways, because a part that refuses one shape may answer another: a plain address-only read, a 16-bit register read as the array sensors want, and a one-byte command read as SMBus parts want. An address is listed if any of the three is acknowledged.

SDA

—
Drives the connector pins as plain outputs so a line can be held while somebody measures at the chip's own pins. A line that stays high at the chip while held low here is not connected. The bus is unusable until released — and a held line blocks every device on it, so release before scanning.

Stimulus

—
Repeats one identical transaction so a scope or logic analyser has a stable trigger. Watch the ninth clock: the slave pulls SDA low there to acknowledge, and a line that stays high is a part that is not answering.
